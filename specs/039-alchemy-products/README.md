# 炼金术产物详表：品质提炼

本 spec 是 038-alchemy-system 的子 spec，详细定义所有炼金产物的数据。所有产物都是同品类中品质最好的那一档——依然是寻常之物，只是好到了极致。

---

## 精华类

蒸馏操作的核心产出，从物品中提取的品质精华。精华本身也是炼金材料，用于注养或升华操作。

| 产物 | 原料类型 | 外观描述 | 用途 |
|------|---------|---------|------|
| 花之精露 | 花卉类 | 清透微粘的液体，颜色随花种不同 | 注养花卉/香包/香水类物品，提升"灵气" |
| 果实精萃 | 水果类 | 浓稠的琥珀色浆液，果香扑鼻 | 注养食材/料理，提升"风味" |
| 粮之精粹 | 粮食类 | 乳白色粉末，触感细腻如脂 | 注养饲料/食材，提升"营养" |
| 矿之精华 | 矿石/黏土类 | 细密结晶，阳光下有金属光泽 | 注养工具/建材，提升"耐久" |
| 木之精魂 | 木材类 | 半透明油状物，有木质清香 | 注养木制品/家具，提升"温润" |
| 草之精萃 | 香草/药材类 | 深绿色浓汁，气味强烈 | 注养药品/香料，提升"效力" |
| 绒之精华 | 棉花/布料类 | 棉絮状轻羽，触手生温 | 注养布制品/饰品，提升"柔软" |

## 贤者之石（终极目标）

> *"不是点石成金，而是让金更金。"*

炼金术的至高追求。它不是神话中的万能石，而是一块温润的、仿佛有生命的石头——一个老匠人毕生心血的结晶。

**获取方式：**
- 需要 10 级炼金
- 特殊任务链：完成一系列精炼挑战（如：精炼 10 种不同材料、成功 5 次大成功等）
- 制作材料：每一种精华各一份 + 任意 3 种精炼材料

**效果（永久被动，放置在工作台上生效）：**
- 选择以下效果之一，不可逆转：

| 选择 | 效果 |
|------|------|
| 大师之手 | 所有炼金操作成功率 +15% |
| 亲和之证 | 宠物亲密度获取速度 +20% |
| 丰饶之证 | 所有产出有 10% 概率额外获得一个 |
| 专注之证 | 炼金时大成功概率 +10% |

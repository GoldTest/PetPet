# 季节活动系统

## Overview

建立完整的季节活动体系，让 PetPet 每周都有事可做。采用双层结构：**周常轮换活动**（12 周循环）+ **大型节日活动**（覆盖在轮换上）。

## 设计要求

### 双层活动体系

**第一层：周常轮换（12 种）**
钓鱼大赛、烹饪大会、宠物选美、采集嘉年华、许愿周、折扣市集、双倍丰收、宝藏猎人、宠物才艺秀、邻里互助、炼金开放日、年终庆典 — 12 周一循环。

**第二层：大型节日**
元旦、春节、情人节、端午、中秋、万圣、圣诞 — 节日期间取代或叠加当周轮换活动。

### 活动表日历
独立的环形日历页面，全年视图，当前活动高亮 + 倒计时，即将到来活动预告，点击展开详情。

### 每个活动标配
- 限定物品（3~5 种）
- 限定任务链（3~5 步）
- 轻度小游戏或独特交互
- 特殊视觉/音效
- 活动专属成就

## Scope

### In
- 活动表日历框架（UI + 调度引擎）
- 12 种周常轮换活动
- 7 个大型节日
- 四季更替特殊事件
- i18n 双语支持

### Out
- 不与 Mod 系统深度耦合（Mod 可额外定义活动，但核心框架不依赖 Mod）
- 不实现实时多人联机（异步社交即可）

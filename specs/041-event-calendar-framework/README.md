# 活动表/日历框架

## Overview

活动表是季节活动系统的核心调度框架，提供日历 UI 和活动调度引擎。所有活动（周常 + 节日）通过此框架注册、调度、展示。

## 核心设计

### 活动调度引擎
- 活动定义 DSL：名称、时间窗口、类型（周常/节日）、优先级、冲突处理规则
- 活动状态机：预告 → 进行中 → 结束 → 结算
- 基于游戏内 tick 系统检查活动状态切换
- 冲突处理：节日优先级高于周常，节日期间暂停对应周常

### 日历页面 UI
- 独立日历页面，全年环形视图
- 按月/周切换浏览
- 当前活动高亮 + 倒计时
- 即将到来活动预告气泡
- 已结束活动灰显可回顾
- 点击活动卡片展开详情面板（奖励列表、任务、攻略指引）

### 活动详情面板
- 活动名称、时间、剩余时间
- 限定物品列表（可预览）
- 任务链进度
- 活动专属成就
- 快速跳转按钮（如钓鱼大赛→跳转到钓鱼区）

### 数据存储
- 活动状态存入 PetState
- 已完成活动记录（用于成就、回顾）
- 跨年活动历史保留

## Requirements
- [ ] 活动调度引擎（DSL + 状态机 + tick 检查）
- [ ] 日历页面 UI（全年视图、月/周切换）
- [ ] 活动卡片展示（状态、倒计时、详情）
- [ ] 冲突处理规则（节日 vs 周常）
- [ ] 活动详情面板
- [ ] 活动数据持久化存储
- [ ] 活动历史记录
- [ ] i18n 双语支持

## Non-Goals
- 不依赖 Mod 系统（框架独立）
- 不实现实时推送通知（基于 tick 轮询）

## Technical Notes
- 独立模块: src/core/eventCalendar.ts
- 独立 UI 组件: src/ui/EventCalendar.tsx
- 活动 DSL 以 JSON 格式定义
- 参考现有 dailyWishes 的日期键机制

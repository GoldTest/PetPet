# 许愿池/幸运轮盘：每日抽奖系统

> **Status**: planned · **Priority**: medium · **Created**: 2026-07-27

## Overview

许愿池是每日抽奖系统，玩家每天可免费许愿一次，获得随机奖励。简单但上瘾的机制，提供每日登录的额外动力，同时消耗游戏内金币作为经济回收口。

## 核心设计

### 许愿机制
- 每日免费许愿 1 次（重置时间同每日任务）
- 额外许愿消耗金币（首次 50，之后递增 +20/次，日上限 5 次）
- 投币动画：抛硬币 → 水面涟漪 → 光芒 → 弹出奖励
- 累积许愿次数提升幸运值（保底机制）

### 奖励池
| 稀有度 | 概率 | 奖励示例 |
|--------|------|---------|
| 普通 | 50% | 金币 x20、心情小恢复、普通种子 |
| 稀有 | 30% | 金币 x50、中级物品、稀有树种 |
| 史诗 | 15% | 金币 x100、高级物品、爱心 x2 |
| 传说 | 4% | 金币 x300、传说物品、提升卡天数 |
| 隐藏 | 1% | 特殊外观/成就/限定物品 |

### 幸运值系统
- 每次未中传说增加隐藏幸运值 +10
- 幸运值满 100 时必出传说
- 中传说后重置幸运值

### 与天气联动
- 晴天：奖励微量提升
- 雨天：鱼类/植物相关奖励概率提升
- 天气奇观（彩虹等）：传说概率翻倍

## Non-Goals
- 不涉及 Mod 系统变更
- 不涉及宠物核心属性大改
- 不实现付费抽卡（只消耗游戏内金币）

# 元旦/新年活动

## Overview

1月1日触发，持续 3 天。以新年倒计时和烟花大会为核心，兼具年度回顾功能。

## 活动内容

### 新年倒计时
- 12月31日跨年夜启动倒计时模式
- 倒计时 1 小时期间，宠物特殊动画（兴奋等待）
- 零点时刻：全屏烟花动画+宠物庆祝动画
- 新年第一声问候（NPC 发来祝福）

### 烟花大会
- 活动期间每晚可放烟花
- 收集烟花材料（竹筒、火药、颜料）
- 制作不同颜色/形状的烟花
- 烟花种类：菊花/牡丹/柳条/爱心/星星
- 放烟花吸引 NPC 围观，增加好感度

### 年度回顾
- 自动生成上一年度游戏报告
- 统计数据：收获总数、钓鱼总数、成就解锁数、与宠物互动次数等
- 年度关键词（根据玩家行为生成）
- 年度报告可分享（截图/保存）

### 新年许愿（与许愿池联动）
- 许愿池新年限定：许愿必出稀有以上
- 新年限定许愿条目："新年运势"

## 限定物品
- 烟花制作材料包（消耗品）
- 各种烟花成品（消耗品，带观赏动画）
- 年度回顾相框（装饰品）
- 新年限定宠物服饰（和服/新年装）
- 新年贺卡（可写给 NPC 获得回礼）

## 限定成就
- 倒计时达人：参与跨年倒计时
- 烟花大师：制作全部 5 种烟花
- 新年新气象：完成所有新年任务

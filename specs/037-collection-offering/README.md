# 收集/献祭系统：套装收集与奖励

> **Status**: planned · **Priority**: medium · **Created**: 2026-07-27

## Overview

收集/献祭系统是星露谷风格的套装收集玩法，玩家需要提交特定物品组合（"套装"）来完成献祭，每完成一套解锁永久奖励。这是最大的消耗系统——**一次性吃掉大量物品**，同时提供明确的长期目标感。

## 核心设计

### 献祭大厅
- 独立页面，展示多个献祭石板
- 每个石板对应一个类别（如"厨房""花园""水域"等）
- 每个石板内有多个"套装"，每个套装需要提交一组特定物品

### 献祭套装设计
| 石板 | 套装 | 需要提交 | 奖励 |
|------|------|---------|------|
| 厨房石板 | 基础食材 | 番茄x3 + 小麦x3 + 鸡蛋x3 | 食谱x1 |
| 厨房石板 | 高级食材 | 鲈鱼x2 + 松茸x2 + 牛奶x3 | 厨房升级 |
| 花园石板 | 春季作物 | 野莓x5 + 薄荷x3 + 玫瑰x2 | 稀有种子 |
| 牧场石板 | 动物产品 | 鸡蛋x5 + 牛奶x5 + 猪肉x3 | 圈舍升级 |
| 水域石板 | 渔获 | 鲫鱼x3 + 鲤鱼x3 + 黏土x5 | 鱼竿升级 |
| 奇观石板 | 稀有物品 | 金鱼x1 + 传说蘑菇x1 + 极光碎片 | 永久 buff |
| 全收集 | 全部完成 | — | 终极奖励（传说外观/称号） |

### 献祭流程
- 玩家查看套装需求 → 从仓库选择物品 → 提交
- 提交后物品被消耗（消失）
- 套装完成后弹出奖励通知
- 完成后在该套装位置显示"✓ 已完成"

### 消耗规模
- 一个套装吃掉 3-5 种物品，每种 2-5 个
- 总计约 20-30 个套装 = 消耗 100-150 件物品
- 是游戏中**最大的单次消耗口**

### 奖励设计
- 实用奖励：食谱、升级、种子、工具
- 收藏奖励：限定装饰、饰品、称号
- 终极奖励：全部完成后的传说级奖励

## Requirements
- [ ] 献祭大厅 UI（石板展示、套装进度）
- [ ] 6 个石板设计（每个 3-5 个套装）
- [ ] 20+ 个献祭套装定义
- [ ] 提交/消耗流程
- [ ] 奖励系统（实用+收藏+终极）
- [ ] 完成进度追踪
- [ ] 与仓库系统的交互（从仓库取物提交）
- [ ] 新增献祭专属物品到物品表
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不涉及 Mod 系统变更
- 不替代成就系统（两者并存）
- 不需要排序/重新布置（固定石板位置）

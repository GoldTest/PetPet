# 市场系统：NPC收购与价格波动

> **Status**: planned · **Priority**: medium · **Created**: 2026-07-27

## Overview

市场系统是每日 NPC 收购系统，每天随机生成收购订单，玩家出售多余农产品换取金币。通过价格波动和订单需求引导玩家多样化生产，同时作为稳定的经济调节阀。

## 核心设计

### 每日订单
- 每天刷新 3-5 个 NPC 收购订单
- 每个订单：指定物品 + 数量 + 价格（高于商店售价）
- 订单示例："急需 10 小麦！单价 15 金币（原价 10）"
- 未完成的订单第二天消失，换成新订单

### 价格波动
- 每种物品有基础价格和当日浮动价格
- 价格受以下因素影响：
  - 季节：应季产品价格低，反季价格高
  - 天气：雨天水产价格高，晴天作物价格高
  - 供需：连续多日同类订单 → 价格递减
- 每日价格浮动在基础价的 80%-150% 之间

### 声望系统
- 完成订单增加对应 NPC 的声望
- 声望等级：陌生 → 熟悉 → 朋友 → 挚友
- 高声望解锁：更高价订单、稀有订单、特殊物品回购

### 经济调节功能
- 当某种物品库存过多时，市场收购价自动降低
- 当某种物品短缺时，收购价升高
- 动态平衡各产地的产出价值

## Requirements
- [ ] 每日订单生成（3-5 个/天，随机物品+数量+价格）
- [ ] 价格波动系统（季节/天气/供需影响）
- [ ] NPC 声望系统（4 级）
- [ ] 订单完成/出售流程
- [ ] 经济调节算法（自动平衡产出价值）
- [ ] 市场 UI（订单列表、历史价格、声望进度）
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不涉及 Mod 系统变更
- 不实现玩家间交易（纯 NPC 经济）
- 不替代商店系统（市场是额外售出渠道）

## Technical Notes
- 独立 `market.ts` 模块
- 订单数据存入 `PetState.marketOrders`
- 价格算法参考现有商店定价系统
- 声望参考树园解锁的等级模式

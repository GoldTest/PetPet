# 仓储系统：多产地物品存储管理

## Overview

统一的仓储管理系统，解决多个产地（树园、菜园、麦地、花圃、牧场、发酵、厨房）带来的物品存储压力。提供仓库扩容、分类管理、批量存取、自动整理等功能。

## 核心设计

### 仓库结构
- 全局仓库：所有产地的产出统一存放
- 分类存储：按类别（水果、蔬菜、粮食、香料、动物产品、发酵品、料理）自动分栏
- 堆叠上限：每格可堆叠 99 个同种物品（受仓库等级影响）

### 仓库升级
- 等级 1：基础容量（50 格）
- 等级 2：扩容（100 格）
- 等级 3：大容量（200 格）+ 自动整理
- 等级 4：巨型仓库（500 格）+ 批量存取
- 升级消耗：木材、石材、金币

### 核心功能
- 存入：从产地一键存入仓库
- 取出：选择物品取出到背包
- 整理：自动合并同类物品
- 搜索：按名称/类别筛选
- 批量操作：一键存入/取出同类物品

### 与各产地的接口
- 所有产地的收获物直接进入仓库（而非背包）
- 厨房从仓库取材料（而非从背包）
- 仓库作为各系统的统一物品中转站

## Requirements
- [ ] 仓库数据结构（容量、分类、堆叠）
- [ ] 仓库 UI（分类栏、物品网格、搜索）
- [ ] 存入/取出/整理基础操作
- [ ] 仓库升级系统（4 级，消耗材料）
- [ ] 各产地收获自动入库
- [ ] 厨房从仓库取材料
- [ ] 批量操作（一键存入/取出）
- [ ] 物品搜索和筛选
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不替代宠物背包（背包+仓库共存）
- 不涉及 Mod 系统变更
- 不实现自动出售/交易功能

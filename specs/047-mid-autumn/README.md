# 中秋节活动

## Overview

农历八月十五触发，持续 5 天。以赏月和月饼制作为核心，与许愿池联动。

## 活动内容

### 月饼制作
- 收集面粉、糖浆、馅料（莲蓉/五仁/豆沙/冰皮）
- 使用月饼模具制作不同造型
- 完美月饼可赠送 NPC 获得回礼
- 月饼可食用（心情大幅恢复）

### 赏月（与许愿池联动）
- 中秋夜许愿池变身为"月之神社"
- 许愿免费次数额外+2
- 传说概率翻倍
- 许愿动画变更为月亮主题

### 兔娘互动
- 月兔 NPC 出现在场景中
- 与兔娘对话接取限定任务
- 兔娘赠送限定物品"月兔玩偶"

### 灯笼巡游
- 制作灯笼（纸/竹/LED 三种材料）
- 点亮灯笼后宠物跟随动画变化
- 全服灯笼点亮计数（社区目标）

## 限定物品
- 四种月饼（消耗品）
- 月兔玩偶（装饰品）
- 灯笼（可制作三种）
- 中秋限定宠物服饰（月兔装）

## 限定成就
- 月饼大师：制作全部 4 种月饼
- 月之神社：中秋期间许愿 5 次
- 兔娘的朋友：完成兔娘全部任务
- 中秋圆满：完成所有中秋节任务

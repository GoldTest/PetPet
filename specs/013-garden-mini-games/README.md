# 花园小游戏系统

## 概述

为花园4种操作各配一个即时反馈小游戏，每个<5秒。小游戏为可选加速：点跳过直接获得基础效果，玩小游戏获得额外加成。核心是增加操作娱乐性而非强制门槛。

## 需求

- [ ] 浇水小游戏：节奏点击模式，水滴落到目标区域时精准点击，判定Perfect/Great/Miss
  - Perfect: 生长加速15%，Great: 10%，Miss: 5%（基础效果）
- [ ] 施肥小游戏：3×3消除配对，匹配相同肥料图标
  - 匹配数决定额外掉落概率加成
- [ ] 收获小游戏：翻牌或转盘，翻开3张牌决定掉落品质
  - 牌面组合影响稀有度权重
- [ ] 种植小游戏：拖拽种子到土壤，停留时间影响初始生长进度0-20%
- [ ] 每个操作弹窗有"跳过"按钮，点击直接获得基础效果
- [ ] 小游戏判定结果影响花园状态（加速倍率/掉落权重/初始进度）
- [ ] 小游戏音效反馈（成功/失败/完美各有音效）

## 非目标

- 不强制玩家每次操作都玩小游戏
- 不改变操作的基础效果（仅增加额外加成层）
- 不引入复杂操作（每个游戏<5秒，单手可完成）

## 技术方案

- 新建`src/core/gardenMiniGames.ts` — 小游戏判定逻辑、分数计算、效果映射
- 新建`src/ui/GardenMiniGameModal.tsx` — 小游戏弹窗UI组件
- 修改`src/ui/GardenPage.tsx` — 操作按钮触发小游戏弹窗（或跳过）
- 修改`src/ui/app/useGardenController.ts` — 小游戏结果传递给花园操作
- 小游戏判定使用确定性哈希（与掉落系统一致）
- CSS动画：节奏点击的水滴动画、消除配对的翻转动画、翻牌动画

## 验收标准

1. 点击浇水按钮→弹出小游戏弹窗→可选择玩或跳过
2. 浇水节奏小游戏：水滴动画+点击判定+结果展示，<5秒完成
3. 施肥消除小游戏：3×3格子+配对+结果展示，<5秒完成
4. 收获翻牌小游戏：3张牌+翻开+结果展示，<5秒完成
5. 种植拖拽小游戏：拖拽+停留判定+结果展示，<5秒完成
6. 跳过按钮正常工作，获得基础效果
7. 小游戏结果正确影响加速倍率/掉落权重
8. 音效正确触发
9. 构建通过

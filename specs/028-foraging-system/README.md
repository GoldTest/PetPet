# 采集系统：庭院与岸边野生采集

## Overview

采集系统是休闲探索玩法，玩家在花园周边和水域岸边两个区域采集野生资源，获取厨房料理的辅助食材和特殊材料，与种植/养殖形成互补。采集与钓鱼共享水域场景，视觉统一。

## 核心设计

### 采集区域

#### 区域一：花园周边
- 花园外围的野生地带，产出随季节变化
- 产出：野蘑菇、野果/浆果、野生香草、昆虫(蛋白质)、野花
- 特点：与花园视觉衔接，种植区向外自然延伸

#### 区域二：水域岸边
- 与钓鱼共享水域场景，河岸/湖边区域
- 产出：野菜、水芹、芦苇、可食用花、黏土、螺蛳
- 特点：钓鱼时顺便采集，同一场景双操作

### 采集机制
- 每个区域有 3-5 个刷新点，采集后刷新（5-15 分钟）
- 点击刷新点即可采集，无需等待
- 采集工具：采集篮（可升级，提升采集量）
- 稀有度：普通（绿色光）→ 稀有（蓝色光）→ 传说（金色光）
- 天气影响：雨天蘑菇更多，晴天浆果更多

### 与厨房的联动
- 野生蘑菇/野菜 → 高级料理配料
- 浆果 → 水果补充（与树园互补）
- 昆虫 → 牧场饲料（可喂鸡/猪）
- 可食用花 → 花圃香料补充

### 初始产出示例
| 产出 | 区域 | 稀有度 | 季节 | 用途 |
|------|------|--------|------|------|
| 野蘑菇 | 花园周边 | 普通 | 春秋 | 料理食材 |
| 松茸 | 花园周边 | 传说 | 秋季 | 高级料理 |
| 野莓 | 花园周边 | 普通 | 夏秋 | 水果/果酱 |
| 薄荷 | 水域岸边 | 普通 | 春夏 | 香料/调味品 |
| 水芹 | 水域岸边 | 普通 | 春秋 | 料理食材 |
| 黏土 | 水域岸边 | 普通 | 全年 | 陶器/发酵容器升级 |

## Requirements
- [ ] 两个采集区域（花园周边 + 水域岸边）
- [ ] 刷新点机制（3-5 个点/区域，定时刷新）
- [ ] 10+ 种采集物设计（含稀有度/季节/天气影响）
- [ ] 采集工具升级（采集篮 3-4 级）
- [ ] 点击采集操作（无等待，即时获得）
- [ ] 天气/季节影响
- [ ] 产出接入厨房料理系统
- [ ] 与钓鱼场景共享（水域岸边在同一界面）
- [ ] 新增采集物到物品表
- [ ] 采集图鉴
- [ ] 采集页面 UI
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不涉及宠物核心属性大改
- 不涉及 Mod 系统变更
- 不实现实时物理模拟
- 不替代花园/菜园种植（采集是补充，非主力）

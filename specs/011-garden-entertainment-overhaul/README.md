# 花园娱乐化体系重构

## 概述

将花园从"陪伴慢养成"重构为"娱乐养成"体系。核心变化：缩短种植循环至30分钟基准、4种操作小游戏、全树种图鉴收集、相邻共生加成、堆肥桶资源回收、双轨素材经济（宠物成长+内容解锁）。保留现有3×3地块、天气/季节、工具升级体系。

## 需求

- [ ] 种植循环缩短至30分钟基准（常规树），摇钱树2h，金苹果树4h
- [ ] 4种操作各配一个可选小游戏（浇水节奏、施肥配对、收获翻牌、种植拖拽）
- [ ] 新增堆肥桶：多余物品/枯树碎片→肥料/营养物
- [ ] 全树种图鉴：收获即解锁，图鉴UI，全收集奖励
- [ ] 相邻共生加成：3×3网格中特定树种组合触发效果
- [ ] 双轨素材经济：新素材类型整合进背包，服务于宠物成长和内容解锁
- [ ] 花园UI增强：共生连线可视化、小游戏弹窗、图鉴入口、堆肥桶区域

## 非目标

- 不改变花园的3×3地块布局和解锁机制（已由003完成）
- 不改变天气/季节系统的存在（仅调整数值适配新节奏）
- 不改变工具升级体系的框架（仅扩展堆肥桶为新工具）

## 子Spec

1. garden-time-rhythm — 节奏重构
2. garden-mini-games — 小游戏系统（依赖garden-time-rhythm）
3. garden-compost-bin — 堆肥桶
4. garden-species-book — 全树种图鉴（依赖garden-time-rhythm）
5. garden-synergy — 共生系统
6. garden-material-economy — 双轨素材经济（依赖garden-time-rhythm）

## 验收标准

1. 所有子Spec标记为complete
2. 构建通过（npm run build）
3. 花园操作循环可在30分钟内完成一轮
4. 4种小游戏可正常触发且可跳过
5. 堆肥桶可正常投入/产出
6. 图鉴可正常解锁和查看
7. 共生加成效果正确应用
8. 新素材正确整合进背包系统

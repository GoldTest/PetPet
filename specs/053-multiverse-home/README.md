# 万界之家：万界枢纽基地

> **Status**: planned · **Priority**: high

## 愿景

重新定义 spec 052 的「万界中转站」：中转站不是纯功能选择页，而是玩家与宠物的**万界之家**——万界中的第一个家。家里连通所有跨世界系统：传送门（通往已锚点世界）、交易行（买卖交易）、仓库（物品管理）等设施，随探索进度逐步解锁。

## 核心设计

### 家 = 枢纽基地，设施分区
- 家场景（沿用 052 hub.png 虚空星云悬浮平台）承载多个**设施入口**，每个设施一个独立入口（非列表选择页）
- 设施：传送门（连万界世界）、交易行（交易）、仓库（物品管理），后续可扩展盲盒机、图鉴等
- 各设施入口有独立动效/交互，而非当前 MarketPage 的纯列表按钮

### 传送门与锚点机制（核心）
- 家中传送门只通往**已发现锚点**的世界；未获取锚点的世界**完全隐藏**（不可见，非锁定显示）
- **锚点（Anchor）** 是一种世界物品：只能通过**探索世界**获得（随机传送探索 → 事件/特定物品发现锚点），获得后永久解锁该世界定向传送
- **开局无锚点**：玩家初始只能使用随机传送
- 传送门两种模式：
  1. **定向传送**：通往已锚点世界（免费，需先获得锚点）
  2. **随机传送**：消耗门票（矿物 + 能量），随机传送到未知世界探索，有机会获得新锚点
- 世界传送流程：家 → 传送门设施 → 定向（已锚点世界列表）/ 随机（消耗门票）→ 传送

### 矿物 + 能量系统（传送门票）
- 启动传送门（随机传送）需要特定物品：**矿物 + 能量**
- 矿物系统：矿物资源（获取途径待定——探索世界采集/事件/购买）
- 能量系统：能量累积机制（来源待定——时间恢复/活动/物品）
- 本轮先定义最小框架：门票消耗逻辑 + 资源存储；完整获取途径可后续细化

### 与现有系统的关系
- 仓库、交易行已有独立 spec（026、035），家是它们的**空间载体与统一入口**，不重复实现核心逻辑
- 家不取代主页：主页 = 与宠物日常互动；家 = 空间/跨世界系统入口

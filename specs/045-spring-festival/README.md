# 春节活动

## Overview

农历正月初一触发的大型节日活动，持续 7 天。PetPet 世界里最盛大的节日。

## 活动内容

### 年夜饭烹饪
- 限定食谱：年夜饭套餐（鱼/饺子/年糕/汤圆）
- 收集食材活动期间掉率提升
- 烹饪出完美年夜饭获得限定装饰"团圆饭桌"

### 红包系统
- 每日给宠物发红包（消耗金币，提升心情）
- NPC 回赠红包（随机奖励）
- 累计收发红包数量解锁成就

### 年兽讨喜
- 年兽随机出现在场景中（可爱版，非战斗）
- 投喂年兽获得限定物品"年兽玩偶"
- 年兽出现时背景飘落红色特效

### 春联装饰
- 收集春联碎片合成完整春联
- 贴春联后家园获得节日 buff（心情恢复+20%）
- 限定家具：春联、福字、灯笼

## 限定物品
- 年夜饭套餐（消耗品，大量心情恢复）
- 年兽玩偶（装饰品）
- 团圆饭桌（家具）
- 红灯笼（装饰）
- 新春限定宠物服饰（唐装）

## 限定成就
- 团圆饭：制作完美年夜饭
- 财神到：累计收到 10 个红包
- 年兽朋友：成功投喂年兽 5 次
- 新春大吉：完成所有春节任务

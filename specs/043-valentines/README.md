# 情人节活动

## Overview

2月14日触发，持续 3 天。以双宠互动和巧克力制作为核心，强调宠物陪伴感。

## 活动内容

### 巧克力制作
- 收集可可豆、牛奶、糖、模具
- 制作不同口味巧克力（牛奶/黑巧/白巧/草莓/抹茶）
- 巧克力包装（选择包装纸样式）
- 赠送巧克力给宠物，宠物心情大幅提升
- 赠送巧克力给 NPC，获得回礼

### 双宠互动（如果玩家有多个宠物）
- 两只宠物之间特殊互动动画
- 互相赠送礼物
- 双宠合影（获得限定相框）
- 单宠玩家：宠物与镜子中的自己互动

### 告白信
- 写作小游戏：选择信纸、写信内容、装饰
- 将告白信放入许愿池（特殊动画）
- 获得回信：宠物/ NPC 的回应
- 限定装饰：告白信墙（展示收到的信）

### 玫瑰花园
- 活动期间玫瑰种子限时出售
- 种植玫瑰（生长周期缩短）
- 不同颜色玫瑰不同效果
- 999 朵玫瑰成就

## 限定物品
- 五种巧克力（消耗品）
- 双宠合影相框（装饰品）
- 告白信墙（家具）
- 各色玫瑰花束（装饰品/消耗品）
- 情人节限定宠物服饰（爱心装）

## 限定成就
- 巧克力大师：制作全部 5 种巧克力
- 告白达人：送出告白信
- 玫瑰花园：种植 10 朵玫瑰
- 爱的使者：完成所有情人节任务

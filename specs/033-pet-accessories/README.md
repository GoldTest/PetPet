# 宠物饰品打造：帽子/围巾/配饰

> **Status**: planned · **Priority**: medium · **Created**: 2026-07-27

## Overview

宠物饰品打造系统让玩家用农业产出制作帽子、围巾、眼镜、领结等配饰，装饰宠物外观。与 Mod 系统不冲突——Mod 更换整体皮肤，饰品是额外装饰层，两者可叠加。

## 核心设计

### 饰品类型
| 部位 | 示例 | 主要材料 |
|------|------|---------|
| 头部 | 帽子、王冠、花环 | 布料 + 花卉 + 金币 |
| 颈部 | 围巾、领结、项链 | 布料 + 皮革 + 染料 |
| 眼部 | 眼镜、眼罩、面具 | 木材 + 石材 + 金币 |
| 背部 | 披风、翅膀、背包 | 布料 + 皮革 + 羽毛(采集) |
| 脚部 | 鞋子、袜子、脚环 | 皮革 + 布料 + 染料 |

### 制作系统
- 配方解锁：初始 3 个，其余通过收集/献祭/商人解锁
- 材料消耗：布料、皮革、染料、花卉、木材、金币
- 品质等级：普通 → 精美 → 稀有 → 传说
- 高品质饰品有额外动画效果（如发光、飘动）

### 材料加工链
- 布料：棉花/亚麻(菜园) → 纺线 → 织布
- 皮革：牧场动物皮 → 鞣制 → 皮革
- 染料：花圃花卉 → 提取 → 染色剂
- 羽毛：采集(昆虫/鸟类) → 整理 → 装饰羽毛

### 与 Mod 系统的关系
- Mod 替换宠物整体外观（皮肤、底色）
- 饰品在 Mod 基础上叠加，不冲突
- 饰品可跨 Mod 通用

## Requirements

- [ ] 饰品装备/卸下 UI
- [ ] 与 Mod 系统的兼容层
- [ ] 饰品动画效果（传说品质）
- [ ] 新增饰品相关物品到物品表
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不替代 Mod 系统（两者共存互补）
- 不涉及宠物核心属性大改
- 不实现实时物理模拟

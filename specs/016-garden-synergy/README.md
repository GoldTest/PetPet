# 花园共生系统

## 概述

3×3网格中相邻地块种植特定树种组合时触发共生加成效果。增加花园布局的策略深度，让种树不只是时间管理，还是空间规划。

## 需求

- [ ] 定义共生规则表：哪些树种组合触发什么效果
- [ ] 共生效果类型：
  - 生长加速：邻树生长速度+10%
  - 掉落加成：邻树掉落物数量+1
  - 稀有权重：邻树稀有掉落权重提升
  - 特殊效果：特定组合触发独特效果
- [ ] 共生可视化：相邻树之间显示连线/光效
- [ ] 共生规则可在图鉴中查看（与garden-species-book联动）
- [ ] 共生效果可叠加（多对相邻=多重加成）

## 初步共生规则（待细化）

| 树种A | 树种B | 效果 |
|-------|-------|------|
| 果树 | 护理之树 | 护理树掉落+1 |
| 礼物树 | 果树 | 果树生长+10% |
| 传说树 | 任意 | 邻树经验+20% |
| 同种相邻 | 同种 | 掉落稀有权重+5% |

## 非目标

- 不改变树种本身的效果
- 不引入过于复杂的组合规则（保持5-8种共生关系）
- 共生不改变地块解锁机制

## 技术方案

- 新建`src/core/gardenSynergy.ts` — 共生规则定义、效果计算
- 修改`src/core/garden.ts` — advanceGarden中应用共生加成
- 新建`src/ui/SynergyLines.tsx` — 共生连线可视化组件
- 修改`src/ui/GardenPage.tsx` — 集成连线可视化
- 修改`src/core/lookups/` — 新增共生规则快查表

## 验收标准

1. 相邻地块种植共生树种后效果正确应用
2. 共生连线在花园页面可见
3. 共生效果可叠加
4. 图鉴中可查看共生关系
5. 共生规则表完整定义
6. 构建通过

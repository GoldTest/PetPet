# 发酵/酿酒：调味品与饮品加工

## Overview

发酵/酿酒系统是农业加工链的中间加工环节，利用树园水果、麦地粮食、花圃香草等原料进行发酵，产出酱油、醋、酒、酱料等调味品和饮品。发酵产物供给厨房料理系统，解锁更高级食谱和特殊 buff。

## 核心设计

### 发酵类型
- 酿造酒类：水果 → 果酒，粮食 → 米酒/黄酒
- 酿造调味品：粮食 → 酱油/醋，大豆 → 酱料
- 腌制加工：蔬菜 → 泡菜/腌菜（可跨菜园联动）

### 发酵机制
- 发酵缸/桶：放置原料 → 等待发酵 → 收取成品
- 发酵时间：根据类型不同，10-60 分钟
- 品质因素：原料品质、发酵时长、发酵容器等级
- 陈酿系统：长时间陈酿可提升品质（可选）

### 初始产出示例
| 产出 | 原料 | 发酵时间 | 用途 |
|------|------|---------|------|
| 果酒 | 水果 | 30min | 饮品/料理配料 |
| 米酒 | 水稻 | 45min | 料理配料 |
| 酱油 | 大豆+小麦 | 60min | 料理调味品 |
| 醋 | 水果/粮食 | 30min | 料理调味品 |

## Requirements
- [ ] 发酵容器系统（发酵缸/桶，可升级）
- [ ] 3-4 种发酵类型（酿酒、制酱、酿醋、腌制）
- [ ] 发酵计时机制（10-60 分钟）
- [ ] 品质系统（受原料品质和时长影响）
- [ ] 陈酿系统（可选延长发酵提升品质）
- [ ] 产出接入厨房料理系统（解锁高级食谱）
- [ ] 新增发酵产物到物品表
- [ ] 发酵页面 UI
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不涉及宠物直接食用（发酵产物通过厨房间接使用）
- 不涉及 Mod 系统变更
- 不实现实时物理模拟

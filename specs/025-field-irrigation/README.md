# 水稻种植与农田水利系统

## Overview

在麦地系统基础上新增水稻种植，并引入灌溉/水利系统作为农田管理的新维度。水稻与小麦形成旱作/水作双轨种植体系，灌溉系统影响所有农田（麦地、菜园、花圃）的产出效率。

## 核心设计

### 水稻种植
- 水田地块：独立于旱地（小麦），需要水环境
- 生长周期：比小麦略长，但产量更高
- 产出：水稻 → 稻米（厨房原料）
- 季节适应性：夏季最优，冬季不可种植

### 灌溉系统
- 水源：水井/水渠/水库（逐步解锁）
- 灌溉范围：覆盖麦地、菜园、花圃
- 灌溉等级：手动灌溉 → 自动灌溉 → 智能灌溉
- 效果：提升作物生长速度、减少干旱风险、提高品质

### 水利设施
- 水井：基础水源，小范围灌溉
- 水渠：中级设施，覆盖整片田地
- 水库：高级设施，蓄水+自动灌溉
- 蓄水机制：雨天自动蓄水，旱季消耗储备

### 与现有系统的联动
- 麦地：小麦/水稻共用田地区域，需分配土地
- 菜园：灌溉提升蔬菜生长速度和品质
- 花圃：灌溉影响香草/花卉的存活率

## Requirements
- [ ] 水稻种植（水田地块、生长周期、收获）
- [ ] 水田/旱地切换机制（土地分配）
- [ ] 灌溉系统（水源→灌溉→效果）
- [ ] 水利设施（水井→水渠→水库，三级升级）
- [ ] 蓄水机制（雨天蓄水、旱季消耗）
- [ ] 灌溉对麦地/菜园/花圃的增益效果
- [ ] 新增水稻相关物品到物品表
- [ ] 农田水利 UI
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不修改树园系统（树园不受灌溉影响）
- 不涉及宠物核心属性大改
- 不涉及 Mod 系统变更

## Technical Notes
- 扩展麦地现有代码，新增水田逻辑
- 灌溉系统可参考季节系统的天气影响模式
- 蓄水机制可参考能量系统的恢复/消耗模式

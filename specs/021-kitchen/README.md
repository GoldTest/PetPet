# 厨房：料理制作系统

## Overview

厨房是农业加工链的消费端，消耗树园水果、菜园蔬菜、麦地面粉，通过食谱系统制作料理，为宠物提供 buff 增益。核心玩法是「食谱发现 + 烹饪熟练度 + 料理效果」。

## 核心设计

### 食谱系统
- 食谱 = 特定材料组合 + 烹饪方式 → 料理
- 初始食谱通过引导解锁，高级食谱通过「尝试发现」解锁
- 食谱分为：简单料理（2 材料）、复合料理（3 材料）、特殊料理（4+ 材料）

### 初始食谱示例
| 料理 | 材料 | 效果 | 解锁方式 |
|------|------|------|---------|
| 水果沙拉 | 番茄 + 苹果 | 恢复心情 10 | 默认 |
| 蔬菜汤 | 胡萝卜 + 卷心菜 | 恢复能量 15 | 默认 |
| 面包 | 小麦面粉 | 恢复饱腹 20 | 默认 |
| 番茄炒蛋 | 番茄 + 鸡蛋(树园?) | 恢复心情 15 + 能量 10 | 发现 |
| 蛋炒饭 | 水稻 + 鸡蛋 | 恢复饱腹 25 + 能量 15 | 发现 |
| 蛋糕 | 小麦面粉 + 苹果 + 糖 | 恢复心情 30 | 发现 |

*注：具体材料和效果待设计阶段细化*

### 烹饪机制
- **选择食谱** → **投入材料** → **烹饪等待**（简短，1-5 分钟）→ **获得料理**
- 烹饪中可触发「完美时机」事件（玩家及时点击获得额外效果）
- 失败风险：材料不足或搭配错误 → 产出「焦糊料理」（低收益）

### 熟练度系统
- 每次烹饪增加该食谱的熟练度
- 熟练度等级：新手 → 熟练 → 精通 → 大师
- 高熟练度解锁：更高品质产出、更多掉落、特殊效果
- 全食谱精通触发「料理大师」成就

### 料理效果
- 料理是消耗品，喂给宠物后生效
- 效果类型：心情恢复、能量恢复、饱腹恢复、临时属性加成、特殊效果
- 效果持续时间：即时 or 持续 N 分钟

### 食谱发现
- 玩家可以自由组合材料进行「实验烹饪」
- 如果组合匹配某个未解锁食谱 → 解锁该食谱
- 发现新食谱时弹出通知 + 图鉴记录

## Requirements
- [ ] 食谱数据结构（材料、效果、熟练度等级）
- [ ] 初始 6+ 食谱定义
- [ ] 烹饪操作（选食谱 → 投材料 → 等待 → 获得料理）
- [ ] 熟练度系统（每食谱独立等级）
- [ ] 料理消耗品使用（喂给宠物生效）
- [ ] 食谱发现机制（实验烹饪解锁新食谱）
- [ ] 料理图鉴（已解锁食谱记录）
- [ ] 烹饪页面 UI（食谱列表、烹饪台、材料槽）
- [ ] 与三产地的材料接口（消耗树园/菜园/麦地产出）
- [ ] i18n 双语支持

## Non-Goals
- 不修改树园、菜园、麦地逻辑
- 不实现自动化烹饪（手动操作）
- 不涉及 Mod 系统变更
- 不涉及宠物核心属性大改

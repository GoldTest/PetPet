# 圣诞节活动

## Overview

12月25日触发，持续 7 天。以圣诞树装饰和礼物交换为核心。

## 活动内容

### 圣诞树装饰
- 获取圣诞树（活动起始自动赠送）
- 收集装饰品（彩球、星星、彩带、灯串、雪花）
- 装饰品通过活动任务/采集/制作获得
- 装饰度越高，圣诞老人回礼越好
- 装饰完成的圣诞树在家园展示

### 礼物交换
- 每日可包装一份礼物送给宠物
- 宠物会回赠礼物（随机）
- 与 NPC 交换礼物获得限定物品
- 神秘礼物可开启获得稀有物品

### 雪人堆砌
- 收集雪球（冬季场景自动生成）
- 组合雪人：身体×2 + 装饰（胡萝卜鼻子/纽扣眼睛/围巾/帽子）
- 不同组合产生不同雪人造型
- 雪人保留在家园直到春季融化

### 圣诞老人来访
- 每日圣诞老人随机到访
- 根据圣诞树装饰度 + 乖孩子积分发放奖励
- 乖孩子积分：日常完成任务、帮助 NPC、宠物好心情

## 限定物品
- 圣诞树（家具）
- 各种装饰品（6+ 种）
- 雪人套装（装饰品）
- 圣诞限定宠物服饰（圣诞老人装/麋鹿装）
- 圣诞袜（装饰品，每日可收一次礼物）

## 限定成就
- 圣诞树大师：圣诞树装饰度满级
- 礼物达人：累计交换 10 份礼物
- 雪人艺术家：制作 3 种不同雪人
- 圣诞快乐：完成所有圣诞节任务

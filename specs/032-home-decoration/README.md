# 家园装饰：家具与内装系统

> **Status**: planned · **Priority**: medium · **Created**: 2026-07-27

## Overview

家园装饰系统是最大的长期消耗口，让玩家用农业产出（木材、石材、布料、染料等）和金币制作家具、壁纸、地板、摆件，装饰宠物房间。**永远填不满**，是最理想的资源循环终点。

## 核心设计

### 装饰品类
| 类别 | 子类 | 主要材料 |
|------|------|---------|
| 家具 | 床、桌、椅、柜、书架 | 木材 + 石材 + 金币 |
| 墙面 | 壁纸、挂画、窗户 | 布料 + 染料 + 木材 |
| 地面 | 地板、地毯 | 木材 + 石材 + 布料 |
| 照明 | 台灯、吊灯、蜡烛 | 石材 + 木材 + 金币 |
| 摆件 | 花瓶、雕塑、玩偶 | 黏土 + 花卉 + 染料 |
| 户外 | 栅栏、路灯、花架 | 木材 + 石材 + 铁 |

### 制作系统
- 每个装饰品有配方，消耗特定材料和金币
- 品质等级：普通 → 精美 → 豪华 → 传说
- 高品质需要更多材料 + 更高等级工作台
- 工作台可升级（消耗木材+石材+金币）

### 装饰效果
- 每个物品有"装饰值"，房间总装饰值影响宠物心情
- 特定套装（如"森林系列"）额外加成
- 可自由摆放（网格布局，类似模拟人生简化版）

### 消耗材料来源
- 木材：花园树材 + 麦地稻草 → 加工
- 石材：采集（黏土/石头）→ 加工
- 布料：农业产物（棉花/亚麻）→ 纺织加工
- 染料：花圃花卉 → 提取
- 黏土：水域岸边采集 → 烧制陶器

## Requirements
- [ ] 房间网格布局（可自由摆放/移动家具）
- [ ] 6 类装饰品设计（各 5-10 种）
- [ ] 制作系统（配方 + 材料消耗 + 品质等级）
- [ ] 工作台升级（3-4 级）
- [ ] 装饰值系统（影响宠物心情）
- [ ] 套装收集加成
- [ ] 材料加工链（木材/布料/染料/陶器）
- [ ] 装饰品 UI（房间视图 + 制作界面 + 背包）
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不涉及 Mod 系统变更
- 不替代宠物背包
- 不实现 3D 渲染（2D 俯视/侧视即可）

## Technical Notes
- 独立 `decoration.ts` 模块
- 房间网格数据存入 `PetState.homeLayout`
- 制作系统参考厨房的配方系统模式
- 品质等级参考麦地品质分级

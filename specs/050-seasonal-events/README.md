# 四季更替特殊事件

## Overview

在春分、夏至、秋分、冬至四个节气触发的限时事件，每次持续 1 天。标志着季节更替，带来短暂的特殊效果和活动。

## 四季事件

### 春分·新生祭
- 时间：3月20日左右
- 效果：所有植物生长速度×2，种植收获额外掉落
- 交互：播种仪式（种下一颗"愿望种子"，收获时特殊奖励）
- 限定物品：春之花环（宠物饰品）

### 夏至·仲夏夜
- 时间：6月21日左右
- 效果：夜晚时间延长，夜间活动收益×2
- 交互：萤火虫捕捉（点击萤火虫收集，兑换奖励）
- 限定物品：萤火虫瓶（装饰品）

### 秋分·丰收祭
- 时间：9月23日左右
- 效果：全产地收获量×1.5，出售价格+20%
- 交互：丰收市集（限时 NPC 收购所有物品，价格上浮）
- 限定物品：丰收之角（装饰品）

### 冬至·暖冬节
- 时间：12月22日左右
- 效果：室内活动收益×2，户外消耗减半
- 交互：围炉夜话（与宠物围坐火炉旁，触发特殊对话）
- 限定物品：暖冬毛衣（宠物服饰）

## 设计要点
- 四季事件作为迷你活动，不占用周常/节日档期
- 与周常活动共存，效果叠加
- 仅持续 1 天，轻量级参与
- 每个事件有专属视觉提示（季节更替动画）

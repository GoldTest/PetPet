# 动物牧场：蛋奶肉产出系统

## Overview

动物牧场是农业加工链的第五产地，提供蛋、奶、肉等动物产品，填补厨房料理中动物性原料的空白。养殖场与种植产地形成互补，构建完整的食材供应链。

## 核心设计

### 养殖动物
- 鸡（产蛋）、奶牛（产奶）、猪（产肉）
- 每种动物有成熟周期、产出频率、品质等级
- 动物可通过喂养提升产出品质

### 养殖机制
- 圈舍系统：每种动物有独立圈舍，可升级扩容
- 喂养管理：消耗粮食（麦地产出）喂养动物
- 产出收集：定时收取蛋/奶，成年后屠宰获取肉
- 繁殖机制：动物可繁殖，需公母配对

### 初始产出示例
| 动物 | 产出 | 周期 | 用途 |
|------|------|------|------|
| 鸡 | 鸡蛋 | 每天 | 厨房料理原料 |
| 奶牛 | 牛奶 | 每天 | 厨房料理原料 |
| 猪 | 猪肉 | 7天成熟 | 屠宰后获得肉 |

## Requirements
- [ ] 三种动物基础设计（鸡/奶牛/猪）
- [ ] 圈舍系统（独立圈舍+升级）
- [ ] 喂养机制（消耗粮食产出）
- [ ] 产出收集（定时收取蛋/奶）
- [ ] 屠宰机制（成熟后获取肉）
- [ ] 繁殖系统
- [ ] 品质等级（受喂养质量影响）
- [ ] 产出接入厨房料理系统
- [ ] 新增动物产品到物品表
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不涉及宠物养殖（动物牧场只产出食材）
- 不涉及 Mod 系统变更
- 不实现实时动物动画（静态/简单动态即可）

## Technical Notes
- 参考树种生长周期的计时模式
- 品质等级参考麦地的品质分级系统
- 圈舍升级可参考堆肥桶的升级模式

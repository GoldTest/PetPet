# 天气奇观：稀有天气事件系统

> **Status**: planned · **Priority**: medium · **Created**: 2026-07-27

## Overview

天气奇观系统在现有天气系统基础上，新增稀有天气事件（彩虹、流星雨、极光、萤火虫之夜等），触发特殊交互和奖励，为日常游戏增添惊喜感和仪式感。

## 核心设计

### 奇观种类
| 奇观 | 触发条件 | 持续时间 | 效果 |
|------|---------|---------|------|
| 彩虹 | 雨后天晴（雨→晴切换时 10%） | 30分钟 | 许愿池传说概率翻倍，心情恢复速度+50% |
| 流星雨 | 晴朗夜晚（20%，20点后） | 1小时 | 许愿免费+1，采集刷新速度x2 |
| 极光 | 冬季晴朗夜晚（5%） | 2小时 | 全部产出品质+1级，工作收益+50% |
| 萤火虫之夜 | 夏季晴朗夜晚（15%） | 1.5小时 | 宠物心情缓慢自动恢复，采集物出现概率x2 |
| 花吹雪 | 春季有风天气（10%） | 30分钟 | 花园生长速度x2，收获额外掉落 |
| 丰收之光 | 秋季晴朗白天（10%） | 1小时 | 全产地收获量x1.5 |

### 触发机制
- 基于现有天气系统，在特定天气+季节+时段组合下概率触发
- 触发时全屏视觉效果（渐入动画、背景变化、特效粒子）
- 通知提示："一道彩虹出现在天际！"
- 奇观生效期间，对应效果持续生效

### 玩家交互
- 奇观触发时弹出提示 + 简短描述
- 玩家可点击奇观进行"观赏"（获得额外小奖励）
- 观赏后记录到奇观图鉴

### 奇观图鉴
- 每种奇观首次观赏解锁图鉴条目
- 全收集奖励：永久 buff（如"全奇观见证者"称号）

## Requirements
- [ ] 6 种天气奇观设计
- [ ] 触发条件系统（天气+季节+时段+概率）
- [ ] 全屏视觉效果（渐入、特效、背景变化）
- [ ] 奇观效果实现（buff 加成）
- [ ] 玩家观赏交互（点击获得奖励）
- [ ] 奇观图鉴系统
- [ ] 与现有天气系统集成
- [ ] 通知提示
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不修改现有天气系统的基础框架
- 不涉及 Mod 系统变更
- 不实现实时天气模拟（基于现有 tick 系统）

# 农业加工链：菜园 + 麦地 + 厨房

## Overview

构建从农产品种植到料理加工的完整链路，将树园（水果）、菜园（蔬菜）、麦地（粮食）三产地的产出汇聚到厨房，形成「原料采集 → 料理制作 → 宠物增益」的资源循环。

## 子系统

| 子系统 | Spec | 核心差异化 |
|--------|------|-----------|
| 菜园 | vegetable-garden | 快节奏、小地块、一次性收割、轮作/虫害事件 |
| 麦地 | wheat-field | 批量种植、面积制、品质分级、脱粒加工 |
| 厨房 | kitchen | 食谱系统、烹饪熟练度、料理 buff、食谱发现 |

## 资源流向

```
树园(水果) ─┐
             ├──→ 厨房(料理) ──→ 宠物 buff
菜园(蔬菜) ─┘
麦地(面粉) ──↗
```

## Requirements
- [ ] 菜园系统实现独立种植玩法（区别于树园）
- [ ] 麦地系统实现批量种植玩法
- [ ] 厨房系统实现食谱 + 料理 + buff
- [ ] 三产地产出可被厨房消费
- [ ] 与现有树园系统不冲突，独立页面/入口
- [ ] 新增菜园/麦地专属物品到物品表
- [ ] 新增料理相关物品到物品表
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不修改树园现有逻辑
- 不合并三产地为同一系统（各自独立）
- 不涉及宠物核心属性大改
- 不涉及 Mod 系统变更

# 农业加工链：菜园 + 麦地 + 花圃 + 牧场 + 厨房

## Overview

构建从农产品种植到料理加工的完整链路，将树园（水果）、菜园（蔬菜）、麦地（粮食+水稻）、花圃（香草/花卉）、牧场（蛋奶肉）六产地的产出汇聚到厨房，经发酵/酿酒环节加工调味品后，最终制成料理为宠物提供 buff 增益。仓储系统作为统一物品中转站，贯通全链路。

## 子系统

| 子系统 | Spec | 核心差异化 |
|--------|------|-----------|
| 菜园 | vegetable-garden | 快节奏、小地块、一次性收割、轮作/虫害事件 |
| 麦地 | wheat-field | 批量种植、面积制、品质分级、脱粒加工 |
| 花圃/香料园 | herb-garden | 香草/花卉种植、香料加工、调味品产出 |
| 牧场 | livestock-farm | 蛋/奶/肉产出、动物喂养、繁殖、屠宰 |
| 水利灌溉 | field-irrigation | 水稻种植、水田/旱地切换、灌溉系统、水利设施 |
| 发酵/酿酒 | fermentation | 酿酒、制酱、酿醋、腌制、陈酿系统 |
| 厨房 | kitchen | 食谱系统、烹饪熟练度、料理 buff、食谱发现 |
| 仓储系统 | storage-system | 统一仓库、分类存储、升级扩容、批量存取 |

## 资源流向

```
树园(水果) ─┐
菜园(蔬菜) ─┤
麦地(面粉) ─┤                    ┌─→ 发酵/酿酒 ──→ 调味品 ─┐
花圃(香料) ─┼──→ 仓储系统 ──→ ─┤                             ├──→ 厨房(料理) ──→ 宠物 buff
牧场(蛋奶肉) ┘                    └─→ 直接消费 ────────────┘
水稻(稻米) ──↗
  ↑
灌溉系统 ────┘ (影响所有农田)
```

## Requirements
- [ ] 菜园系统实现独立种植玩法（区别于树园）
- [ ] 麦地系统实现批量种植玩法
- [ ] 花圃系统实现香草/花卉种植与香料加工
- [ ] 牧场系统实现动物养殖与蛋奶肉产出
- [ ] 水稻种植与灌溉水利系统
- [ ] 发酵/酿酒系统实现调味品加工
- [ ] 厨房系统实现食谱 + 料理 + buff
- [ ] 仓储系统作为统一物品中转站
- [ ] 所有产地产出可被厨房消费
- [ ] 与现有树园系统不冲突，独立页面/入口
- [ ] 新增各产地专属物品到物品表
- [ ] 新增料理/发酵相关物品到物品表
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不修改树园现有逻辑
- 不合并各产地为同一系统（各自独立页面）
- 不涉及宠物核心属性大改
- 不涉及 Mod 系统变更

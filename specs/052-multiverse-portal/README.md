# 诸天万界：传送门与万界中转站

> **Status**: in-progress · **Priority**: medium · **Created**: 2026-08-02

## 愿景（长期设想）

> 用户原始设想：**从当前世界跳跃诸天万界，在不同的世界做不同的物品、买卖不同的物品，自行抽取、交易物品。**

诸天万界是 PetPet 的核心扩展框架，取代原「小镇市场」概念：

- 玩家与宠物从首页召唤传送门，穿越到**万界中转站**（独立于当前世界的空间）
- 中转站展示**已探索的世界**；探索新世界 = 解锁新传送门入口
- 每个世界有**独特的世界观、场景、商人与专属物品**——不同世界做不同的物品、买卖不同的物品
- 每个世界可发展独立的交易体系：**自行抽取**（世界盲盒/抽卡）与**交易物品**（跨世界流通）
- 后续可能扩展：流浪商人/行商跨世界游走、世界声望、世界特产收藏图鉴

**世界规划方向（未来扩展，非本次实施）**：精灵森林、海底龙宫、赛博都市、云端仙境……世界观与美术可按现有三世界模式（背景场景 + 一位立绘商人 + 专属商品）无限扩展。

## Overview（阶段 1）

将「市场」系统升级为**诸天万界**框架：宠物与玩家从首页召唤传送门，穿越到万界中转站，在中转站选择已探索的世界，进入不同世界买卖不同物品。本 spec 为阶段 1（框架升级）：传送门召唤 → 中转站 → 世界选择，功能沿用市场系统（spec 036 商人交易）。

## 核心设计

### 首页召唤传送门
- 首页 FeatureRow 按钮改名「诸天万界」
- 点击按钮 → 首页中心浮现悬浮传送门（CSS 动效：缩放浮现、光晕脉冲、旋转光环、背景暗化）
- 点击传送门 → 穿越进入万界中转站；点击传送门以外区域 → 取消召唤
- 传送门旋转动画 26s（慢速旋转）

### 万界中转站
- 中转站背景：虚空星云悬浮平台（`src/assets/market/hub.png`）
- 展示**已探索的世界**（当前 3 个），每个世界一个传送门入口（`portal.png` + 世界名 + 副标题）
- 已探索世界：
  - 古风集市（花见·园艺商人，交易筹备中）
  - 星语集市（夜纱·神秘商人，交易筹备中）
  - 霓虹夜市（珍妮·常驻商人，可交易）

### 世界页
- 点击世界传送门 → 进入该世界场景（沿用 spec 036 集市场景页）
- 每世界一位商人立绘 + 对话面板 + 交易面板（同 036）

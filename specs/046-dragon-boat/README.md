# 端午节活动

## Overview

农历五月初五触发，持续 5 天。以龙舟竞速和粽子制作为核心。

## 活动内容

### 龙舟竞速（小游戏）
- 点击节奏型小游戏：交替点击左右划桨
- 赛道有障碍物（避开浮木）和加速道具（吃粽子加速）
- 成绩分档：普通/良好/优秀/完美
- 每日可参赛 3 次
- 完美成绩获得限定奖励"龙舟模型"

### 包粽子
- 收集粽叶、糯米、馅料（红枣/肉/蛋黄/豆沙）
- 不同馅料组合产出不同口味粽子
- 粽子可食用（体力恢复）或赠送给 NPC

### 艾草香囊
- 野外采集艾草
- 制作香囊（宠物佩戴，活动期间驱散负面状态）
- 活动结束后保留为纪念品

## 限定物品
- 龙舟模型（装饰品）
- 五种口味粽子（消耗品）
- 艾草香囊（宠物饰品）
- 五彩绳（宠物饰品）

## 限定成就
- 龙舟健将：龙舟竞速达到完美 1 次
- 粽子大师：制作全部 5 种口味粽子
- 端午安康：完成所有端午节任务

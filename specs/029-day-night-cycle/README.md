# 昼夜循环：时间视觉与分段玩法

## Overview

昼夜循环系统为游戏添加白天/夜晚视觉切换，不同时间段开放不同活动和交互，增加游戏的沉浸感和时间规划深度。昼夜基于游戏内时间（非实时），与现有天气/季节系统协同。

## 核心设计

### 时间分段
| 时段 | 游戏内时间 | 视觉风格 | 特性 |
|------|-----------|---------|------|
| 清晨 | 5:00-7:00 | 晨光微露 | 宠物起床，心情缓慢恢复 |
| 白天 | 7:00-17:00 | 明亮 | 正常活动，全产地运作 |
| 黄昏 | 17:00-19:00 | 夕阳 | 工作效率提升，采集刷新加速 |
| 夜晚 | 19:00-22:00 | 星空/月光 | 宠物活跃，特殊事件概率提升 |
| 深夜 | 22:00-5:00 | 深蓝/黑暗 | 宠物睡眠，部分操作受限 |

### 视觉变化
- 背景色温渐变（暖晨 → 明亮 → 暖黄昏 → 冷夜 → 深蓝）
- 光影变化（阴影方向/长度）
- 夜晚特效：星星闪烁、月亮、萤火虫
- 室内/室外场景切换灯光

### 时段活动
- 清晨：宠物起床动画、晨间问候
- 白天：全功能开放
- 黄昏：工作收益+15%，适合做料理
- 夜晚：许愿池传说概率提升、钓鱼稀有鱼概率提升
- 深夜：宠物强制睡眠（不可操作，除非叫醒），离线事件触发

### 与现有系统联动
- 天气：夜晚天气效果减半显示（但实际效果不变）
- 花园：夜晚植物继续生长，但不可操作种植
- 钓鱼：夜晚特定鱼种出现
- 采集：夜晚刷新萤火虫等特殊采集物
- 宠物行为：白天活跃，夜晚犯困（操作效率降低 20% 深夜）

## Requirements
- [ ] 5 个时段定义及切换逻辑
- [ ] 视觉风格切换（背景色温、光影、星空/月亮）
- [ ] 时段对活动/操作的影响
- [ ] 宠物昼夜行为差异（活跃/犯困/睡眠）
- [ ] 深夜强制睡眠机制
- [ ] 与现有的天气/季节系统集成
- [ ] 时段 UI 指示器（时钟/天色指示）
- [ ] 昼夜过渡动画
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不实现实时时钟（基于游戏内 tick 时间）
- 不涉及 Mod 系统变更
- 不修改宠物核心属性
- 不实现物理光照模拟（CSS 视觉效果即可）

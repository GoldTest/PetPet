# 堆肥桶资源回收系统

## 概述

新增堆肥桶作为花园资源回收设施。玩家可将多余物品、枯树碎片投入堆肥桶，经过时间后产出肥料和营养物。解决多余物品无处去的问题，同时让枯树从纯惩罚变为资源来源。

## 需求

- [ ] 新增堆肥桶界面区域（花园页面内，3×3网格旁）
- [ ] 堆肥桶有3个投入槽位，每个槽位独立计时
- [ ] 输入类型：
  - 多余水果/护理品 → 基础肥料（30min产出）
  - 枯树碎片（清理枯树获得） → 生长加速剂（1h产出）
  - 特定组合投入 → 稀有肥料（2h产出，探索驱动）
- [ ] 堆肥桶等级系统（Lv1-3），等级影响产出效率和品质
- [ ] 堆肥桶升级费用与工具升级体系融合
- [ ] 投入物品有动画反馈
- [ ] 产出收取有音效反馈
- [ ] 枯树清理改为产出枯树碎片（而非纯金币消耗）

## 非目标

- 不改变堆肥桶以外的花园操作
- 不引入过于复杂的配方系统（3种投入类型足够）
- 堆肥桶不占用3×3地块（独立区域）

## 技术方案

- 新建`src/core/compostBin.ts` — 堆肥桶状态、投入/产出逻辑、等级系统
- 修改`src/core/garden.ts` — clearWitheredTree改为产出枯树碎片
- 新建`src/ui/CompostBinPanel.tsx` — 堆肥桶UI面板
- 修改`src/ui/GardenPage.tsx` — 集成堆肥桶面板
- 修改`src/core/petTypes.ts` — 扩展GardenState添加compostBin字段
- 修改`src/core/saveCodec.ts` — 数据迁移兼容
- 修改`src/core/items.ts` — 添加枯树碎片等新物品

## 验收标准

1. 花园页面可见堆肥桶面板
2. 可将物品投入堆肥桶槽位
3. 投入后显示倒计时
4. 倒计时结束后可收取产出
5. 枯树清理产出枯树碎片
6. 堆肥桶可升级，等级影响产出
7. 存档迁移兼容
8. 构建通过

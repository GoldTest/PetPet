# 钓鱼系统：水域休闲采集

## Overview

钓鱼系统是休闲采集玩法，玩家在专属水域进行钓鱼，获取鱼类食材供给厨房料理系统，同时作为放松娱乐活动。钓鱼与农业加工链形成水/陆双线食材供应。

## 核心设计

### 钓鱼场地
- 独立水域页面（池塘/河流/湖泊，随等级解锁）
- 每个场地有不同鱼种分布和稀有度
- 天气/季节影响鱼种出现率和咬钩概率

### 钓鱼机制
- 抛竿 → 等待 → 咬钩提示 → 收竿（简单 QTE 或时机判定）
- 钓鱼耗时：30秒-2分钟（可加速）
- 鱼竿等级：竹竿 → 铁竿 → 碳素竿 → 神竿（影响钓率和鱼种）
- 鱼饵系统：不同鱼饵吸引不同鱼种

### 鱼种设计
| 鱼种 | 稀有度 | 场地 | 用途 |
|------|--------|------|------|
| 鲫鱼 | 普通 | 池塘 | 厨房食材 |
| 鲤鱼 | 普通 | 池塘/河流 | 厨房食材 |
| 鲈鱼 | 稀有 | 河流 | 高级料理 |
| 三文鱼 | 稀有 | 湖泊 | 高级料理 |
| 金鱼 | 传说 | 全部 | 观赏/装饰 |
| 垃圾 | 杂物 | 全部 | 堆肥/回收 |

### 与厨房的联动
- 鱼类作为厨房料理的蛋白质来源（与牧场蛋奶肉互补）
- 解锁鱼类专属食谱（鱼汤、烤鱼、鱼生等）
- 稀有鱼可做特殊料理 buff

## Requirements
- [ ] 钓鱼场地系统（3个场地逐步解锁）
- [ ] 钓鱼操作流程（抛竿→等待→咬钩→收竿）
- [ ] 6+ 种鱼设计（含稀有度分级）
- [ ] 鱼竿升级系统（4级）
- [ ] 鱼饵系统
- [ ] 天气/季节影响
- [ ] 鱼类产出接入厨房
- [ ] 新增鱼类/鱼竿/鱼饵到物品表
- [ ] 钓鱼图鉴（已钓到鱼的记录）
- [ ] 钓鱼页面 UI

## Non-Goals
- 不涉及宠物直接下水
- 不涉及 Mod 系统变更
- 不实现实时物理模拟（简化的时机判定即可）

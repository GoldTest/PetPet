# 花圃/香料园：香草与花卉种植

## Overview

花圃/香料园是农业加工链的第四产地，专注于香草、花卉、香料作物的种植。产出可用于厨房料理调味、制作香囊/装饰品，也可作为宠物礼物或特殊事件道具。

## Requirements
- [ ] 花圃地块系统（独立于树园/菜园/麦地的种植界面）
- [ ] 香草/花卉作物种类设计（至少 4-6 种）
- [ ] 种植与收获机制（快节奏，类似菜园风格）
- [ ] 作物生长周期与季节影响
- [ ] 香料加工（晾晒/研磨等简单加工）
- [ ] 产出接入厨房料理系统（作为调味品/辅料）
- [ ] 新增物品到物品表（香草、花卉、香料、加工品）
- [ ] i18n 双语支持 (zh-CN + en-US)

## Non-Goals
- 不修改现有树园/菜园/麦地逻辑
- 不涉及宠物核心属性大改
- 不涉及 Mod 系统变更

## Technical Notes
- 复用菜园的快节奏种植模式
- 香料加工可参考麦地的脱粒加工模式
- 产出作为厨房料理的可选配料，提供额外 buff 或解锁新食谱

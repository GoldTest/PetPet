# 万圣节活动

## Overview

10月31日触发，持续 3 天。以不给糖就捣蛋和南瓜灯制作为核心。

## 活动内容

### 不给糖就捣蛋
- 宠物出门拜访 NPC 索要糖果
- 每次获得随机糖果（不同口味，效果不同）
- 不给糖时 NPC 做鬼脸（宠物心情小降，但获得恶作剧积分）
- 恶作剧积分可兑换限定物品

### 南瓜灯制作
- 采集南瓜（活动期间野外刷新）
- 雕刻南瓜灯（选择表情：开心/邪恶/惊讶/呆萌）
- 南瓜灯放置在家园门口（装饰 + 吸引 NPC 给糖）
- 不同表情吸引不同 NPC

### 幽灵装扮
- 收集幽灵布碎片（完成活动任务获得）
- 合成完整幽灵装扮
- 穿上后宠物外观变为幽灵形态（仅活动期间）
- 与其他宠物互动时有特殊动画

### 糖果工坊
- 使用基础糖果+材料制作高级糖果
- 高级糖果有特殊效果
- 糖果可交易或赠送

## 限定物品
- 四种南瓜灯（家具）
- 幽灵装扮（服饰）
- 各种糖果（消耗品，带特殊效果）
- 万圣限定家具（蜘蛛网、墓碑装饰）

## 限定成就
- 不给糖就捣蛋：收集 10 种糖果
- 雕刻大师：制作全部 4 种南瓜灯表情
- 幽灵现身：合成幽灵装扮
- 万圣狂欢：完成所有万圣节任务

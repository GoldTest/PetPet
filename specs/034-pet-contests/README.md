# 宠物比赛与节日活动系统

> **Status**: planned · **Priority**: medium · **Created**: 2026-07-27

## Overview

宠物比赛与节日活动系统是周期性消耗事件，玩家报名费消耗金币+物品，比赛消耗特殊道具，获胜获得稀有奖励。定期举办形成周期性消耗节奏，同时为社交和成就感提供出口。

## 核心设计

### 比赛类型
| 比赛 | 评判标准 | 消耗 | 频率 |
|------|---------|------|------|
| 选美大赛 | 饰品+心情+健康 | 报名费200金币 | 每周 |
| 才艺表演 | 玩耍次数+熟练度 | 报名费300金币+特殊道具 | 每两周 |
| 料理大赛 | 料理品质+种类 | 提交料理作品 | 每月 |
| 花园评比 | 花园品种+装饰 | 报名费500金币 | 每月 |

### 比赛机制
- 报名消耗金币 + 可能消耗物品
- 比赛结果基于宠物属性+装备+提交物品品质
- 排名：1-3 名获稀有奖励，参与奖保底
- 赛季制：每季度总积分排名，年度总冠军

### 奖励
| 名次 | 奖励 |
|------|------|
| 冠军 | 传说物品/限定饰品/大量金币 |
| 亚军 | 史诗物品/稀有饰品/金币 |
| 季军 | 稀有物品/饰品碎片/金币 |
| 参与 | 金币+普通物品 |

### 节日活动
- 与现有节日系统（dateRewards）联动
- 节日期间举办专属比赛 + 限时商店 + 特殊事件
- 节日限定物品（过期绝版）

### 消耗回收
- 报名费消耗金币
- 特殊比赛道具消耗（如"参赛券"由材料合成）
- 料理大赛消耗厨房产出
- 花园评比消耗花卉/装饰品

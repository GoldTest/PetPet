# 周常轮换活动

## Overview

12 种周常活动按周循环，确保玩家每周都有新鲜事可做。每轮 12 周，一年约 4.3 轮。

## 12 种周常活动

| 周次 | 活动名称 | 类型 | 玩法说明 |
|------|---------|------|---------|
| 第 1 周 | 钓鱼大赛 | 竞速 | 限时钓特定鱼种，称重排名，第一名获得限定鱼竿皮肤 |
| 第 2 周 | 烹饪大会 | 制作 | 提交特定料理评分，分数越高奖励越好，限定食谱 |
| 第 3 周 | 宠物选美 | 展示 | 根据心情+装扮+清洁度+健康评分，冠军获得王冠头饰 |
| 第 4 周 | 采集嘉年华 | 竞速 | 野外采集物双倍刷新，收集指定目标兑换奖励 |
| 第 5 周 | 许愿周 | 福利 | 许愿池免费次数+1，传说概率翻倍，心情恢复加速 |
| 第 6 周 | 折扣市集 | 经济 | 商人收购价+20%，部分商品 8 折，限时商品上架 |
| 第 7 周 | 双倍丰收 | 生产 | 全产地收获量×2，生长速度+50% |
| 第 8 周 | 宝藏猎人 | 探索 | 地图随机刷新宝箱（3-5个），限时开启，内含稀有物品 |
| 第 9 周 | 宠物才艺秀 | 展示 | 宠物展示已学技能，多维度评分，赢取奖杯装饰品 |
| 第 10 周 | 邻里互助 | 社交 | 拜访/送礼/串门收益×2，好友事件触发率提升 |
| 第 11 周 | 炼金开放日 | 制作 | 炼金成功率+15%，材料消耗-20%，限时配方解锁 |
| 第 12 周 | 年终庆典 | 综合 | 全年成就回顾，专属限定奖励，活动轮换重置 |

## 设计要点
- 每周一凌晨自动切换活动
- 活动期间全屏顶部通知横幅
- 每个活动有专属渐变主题色
- 活动对应专属成就
- 节日活动期间暂停对应周常（节日优先级更高）

## Requirements
- [ ] 12 种周常活动定义与实现
- [ ] 每周自动轮换 + 通知
- [ ] 每个活动独特机制（独立模块）
- [ ] 活动专属成就（12+ 个）
- [ ] 活动专属限定物品（每种 2-3 件）
- [ ] 与活动表框架集成
- [ ] 节日冲突处理
- [ ] i18n 双语支持

## Non-Goals
- 不实现实时排名（仅展示玩家自己的完成度）
- 不与 Mod 系统耦合

## Technical Notes
- 独立模块: src/core/weeklyEvents.ts
- 每个活动作为独立子模块: src/core/weeklyEvents/fishingTournament.ts 等
- 活动配置以 JSON 定义，便于扩展

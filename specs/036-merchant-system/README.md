# 商人系统：流浪商人与稀有交易

> **Status**: planned · **Priority**: medium · **Created**: 2026-07-27

## Overview

商人系统是流浪商人机制，不定期来访，出售稀有物品和限量商品，接受以物易物。与市场系统的区别：市场是**每日固定**的 NPC 收购（卖东西），商人是**随机来访**的稀有交易（买东西/换东西）。

## 核心设计

### 商人来访
- 随机来访（概率：每日 30%，若未出现则累积概率）
- 来访时弹出通知："一位神秘的商人到达了！"
- 商人在店停留 24 小时（游戏内时间）
- 不同商人有不同风格和商品池

### 商人类型
| 商人 | 商品特点 | 交易方式 |
|------|---------|---------|
| 杂货商人 | 普通稀有物品、种子、工具 | 金币购买 |
| 古董商人 | 传说物品、家具、装饰品 | 金币+稀有材料 |
| 异域商人 | 异国种子、特殊香料、食谱 | 以物易物 |
| 神秘商人 | 提升卡、限定外观、特殊道具 | 特殊货币/爱心 |

### 交易机制
- 金币购买：直接标价，通常高于商店
- 以物易物：商人指定需要某种物品，玩家用物品交换
- 限量：每个商人每种商品限购 1 个
- 物品刷新：每次来访商品不同

### 与市场系统的区别
| 维度 | 市场系统 | 商人系统 |
|------|---------|---------|
| 频率 | 每天固定 | 随机来访 |
| 方向 | 玩家→NPC（卖） | NPC→玩家（买/换） |
| 商品 | 日常物品 | 稀有/限定物品 |
| 价格 | 浮动，高于商店 | 溢价，高于市场 |
| 声望 | 有 | 无 |

## Non-Goals
- 不替代市场系统（两者互补）
- 不涉及 Mod 系统变更
- 不实现实时多人交易

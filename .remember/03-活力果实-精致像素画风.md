## 完整提示词（v2 通过版）

```
用 SenseNova 文生图生成一张"精致像素风"图标：活力果实（一颗圆润饱满的紫蓝色发光魔法果实，游戏道具）。居中构图，比例 1:1（尺寸 2048x2048）。

**风格：REFINED PIXEL ART 精致像素风——像素颗粒明显但细腻，轻微抗锯齿过渡，轮廓干净利落，每个颜色区域分 2-3 层明暗色块（深色底→主色→高光点），高光清晰聚焦、阴影层次简单分明，色块干净不糊。像素感优先，细节点到为止，不做微观细节堆砌。不是粗颗粒复古像素，不是扁平卡通，不是写实。**

**内容：** 一颗圆润饱满的紫蓝色魔法果实（活力果实）——果实主体用三层明暗色块表现：深紫蓝暗部、亮紫蓝主色、左上角一处清晰的高光点；顶部一根嫩绿色卷曲果蒂；果实周围一圈紧贴轮廓的细淡紫色光晕（光晕收紧在果实边缘，不做大范围外溢渐变）。不需要果皮纹路、不需要星芒、不需要发光星点、不需要颗粒质感。

**要求：**
- 主体占画面 70% 以上、居中构图
- bright magenta background (#FF00FF) 品红纯色背景（用于后续抠图）
- 主体颜色避免品红/粉紫系（高光、光晕、果蒂都不要用接近品红的浅粉色，否则抠图会被误删）
- refined pixel art, crisp clean edges, flat color blocks with 2-3 shade steps, clear focused highlights, simple clear shading, pixel aesthetic first
- no text, no numbers, no labels
- 尺寸 2048x2048 (1:1)
```

## 失败版对比（v1 被否原因）

v1（20260801_193211）被否，两大问题：
1. **细节堆砌丢失像素感**——要求了星芒能量纹路、发光星点、颗粒质感等微观细节，结果像普通插画不像像素
2. **抠图空心**——果实内部浅紫高光/光晕距品红背景 <120 被误染成纯品红后抠除（bg=(235,6,207)，果内浅色 (239,42,219) 等距离太近）

**修正手段（v2 生效）：**
- 画风定义改为"色块 2-3 层、高光聚焦、细节克制"
- 内容段删掉纹路/星点/颗粒，光晕收紧贴轮廓
- 要求段新增"主体颜色避免品红/粉紫系"

**抠图教训：** 主体浅色区可能被"距背景<120"误染。兜底方案为边缘连通域法（BFS 从图像四边扩展，只染色与边缘连通的背景像素），scipy 不可用时用 PIL+numpy 手写 BFS（8 连通）。

# 蔬菜图标生成 — 真实纹理像素风

## 批次信息

- **日期：** 2026-08-02
- **模型：** SenseNova U1 Fast
- **风格：** 真实纹理像素（REALISTIC TEXTURE）— 见 `style-library/styles/01-真实纹理像素.md`
- **目标：** 蔬菜园各作物生长阶段图标（3 阶段：幼苗/生长/成熟）

## 经验教训

### 1. 不需要种子阶段图标

蔬菜图标只需 3 个阶段：
- `icon_{crop}_sprout.png` — 幼苗（Stage 2）
- `icon_{crop}_growing.png` — 生长期（Stage 3-4）
- `icon_{crop}.png` — 成熟/可收获（Stage 5）

不需要种子阶段（Stage 1）图标。

### 2. 不要泥土/土壤

用户明确表示不要泥土、不要土壤、不要土地、根部不可见。画面干净简洁，主体直接可见。

### 3. 多阶段生成方式

可以使用两种方式：
- **单张生成**（1:1 2048x2048）：每阶段独立生成，画风可控但效率低
- **多对象拼图**（21:9 3072x1376）：3 个对象水平排列，一次生成后切分，画风一致性好

但本次使用的是单张生成方式，每次生成 1 个阶段。

### 4. 提示词结构

完整提示词模板：

```
用 SenseNova 文生图生成一张"真实纹理风格"像素风图标：[作物名]的**[第N生长阶段——阶段名]**。单物体居中构图，比例 1:1（尺寸 2048x2048）。

**风格：REALISTIC TEXTURE 真实纹理像素风——可见清晰像素颗粒（chunky pixel grid）、硬边像素无平滑抗锯齿、真实材质感，16-bit 复古游戏画风，颜色深而丰富、高对比度、自然大地色系。不要柔和渐变、不要粉彩淡色、不要平滑柔光。**

**内容：** [阶段内容描述——形态/结构/内容物/颜色/数量递进]。整体干净简洁，不要泥土，不要土壤，不要土地，根部不可见，不要任何背景杂物。

**要求：**
- bright magenta background (#FF00FF) 品红纯色背景（用于后续抠图）
- pixel art with REALISTIC TEXTURE, 16-bit retro game art, chunky pixel grid, hard-edged pixels, rich deep colors, high contrast
- no text, no numbers, no labels
- 尺寸：2048x2048 (1:1)
```

### 5. 后处理流程

```powershell
python scripts/chroma_key.py <input.png> <output.png> auto 70 128x128 16
```

- tolerance: 70（品红背景一般够用）
- 输出内容尺寸: 128x128
- padding: 16px（最终画布 160x160）

**重要经验：背景色选择**
- 品红背景 (#FF00FF) 对于含棕色/红色前景（如土壤）的图抠不干净，因为棕色含红色成分
- 绿色背景 (#00FF00) 对于含绿色叶子前景的图抠不干净
- **蓝色背景 (#0000FF) 效果最好**，因为蓝色与棕色土壤、绿色叶子、橙色/红色果实色差都很大
- 蓝色背景建议 tolerance 120，手动指定 key color: `"0,0,255"`

### 7. 自然形态描述的重要性（关键经验）

幼苗/生长阶段的图标要**准确描述作物的真实自然形态**，不能写笼统的通用描述。

**失败的番茄幼苗描述：**
> "两片嫩绿圆润子叶，浅绿色茎秆细短，叶片有清晰叶脉纹理"

→ AI 生成的是"通用小苗"，没有任何番茄特征，看起来假。

**成功的番茄幼苗描述：**
> "底部有两片细长的子叶（长条形，不是圆形），从子叶之间长出真正的番茄叶——叶片是深裂的羽状复叶，像蕨类植物一样有裂片，边缘有锯齿"

→ 准确的形态规格让 AI 生成有辨识度的番茄苗。

**原则：** 每种作物有其独特的幼苗形态，提示词中必须写清楚该物种的独有特征（叶形、叶缘、茎秆特征），不能通用化描述。

常见蔬菜幼苗特征：
- **番茄：** 子叶细长条形，真叶为深裂羽状复叶（蕨叶状），茎有绒毛
- **胡萝卜：** 子叶细长线形，真叶为羽状复叶（细碎），像胡萝卜叶子
- **卷心菜：** 子叶心形/肾形，真叶为圆形有柄，叶面有蜡粉
- **洋葱：** 子叶管状，真叶为管状中空，直立生长
- **土豆：** 羽状复叶，小叶卵形，整体像小树

### 8. 生成经验

- 新生成的图标先放在 `opencode_temp_icons/` 供用户评估，通过后再替换到 `src/assets/icon/veg/`
- 用户评估通过后，需要更新 `src/assets.ts` 中的 import 路径
- 每次生成 1 个作物，让用户评估后再继续下一个
- **绝对禁止清空 `opencode_temp_icons/` 目录**——已评估通过的图标存在该目录中待替换，清空会导致丢失（每个作物评估通过后只在新作物开始时清空，但必须保留所有已通过图标的副本）
- 临时目录只放最新一批正在评估的图标，已通过的图标应单独保留或直接替换到正式目录

### 10. 抠图 tolerance 安全窗口法（关键经验）

**背景：** tolerance 过大（如 140）会把叶片颜色也抹掉——叶片深绿距背景色 ~200，落入渐晕区 [tol, 2*tol] 被减淡成半透明，看起来"叶片被抠没了"。

**正确流程：先分析再抠图，一步到位：**

```powershell
python scripts/chroma_key.py analyze <raw.png>
```

analyze 输出背景/主体距离分布 + 建议 tolerance，然后：

```powershell
python scripts/chroma_key.py <raw.png> <output.png> <R,G,B> <建议tolerance> 128x128 16
```

**原理（安全窗口）：**
- 背景高度统一：99% 背景像素距主色 ≤ p99（如 45）
- 主体核心（叶片/果实）距背景色 ≥ 200+
- 背景与主体之间有少量过渡混合像素（边缘反锯齿，被渐晕是正常且有益的——边缘柔和）
- 安全窗口：`tolerance >= bg_p99` 且 `2*tolerance <= subject_p10`，取中点
- 背景/主体距离分析不可靠时（背景渐变、非纯色），先跑 analyze 看分布再定 tolerance

**案例：** 胡萝卜成熟图背景 (3,169,231)，bg p99=45，subject p10=210 → 窗口 [45, 105] → 建议 58（实际 55 也完美）。

### 11. 用户自写提示词（推荐优先使用）

用户反馈：**简短的自写提示词比 AI 写的一长串更好用**。用户提示词抓住了三个关键点（主体形态 + 背景规格 + 视角），风格段由 AI 补即可。

**胡萝卜成熟植株（用户版，已验证效果）：**

> 高精度、高画质像素化的成熟胡萝卜作物，完整植株，背景为亮蓝色匀称无杂色，半截胡萝卜露出地面，叶片蓬松发散

使用方式：主体描述用用户版，补充风格段（REALISTIC TEXTURE）+ 要求段（纯色平涂背景、pixel art 关键词、no text、尺寸 2048x2048）。

**生成植株类作物注意：**
- 用户要"植物形态"（种在土里的植株：叶片+露出部分），不是"果实形态"（一根完整胡萝卜）
- 视角要**平视**（与植物齐平），不要俯视——俯视容易生成"一坨草"
- 橙色部分（辨识特征）占比要足够（≥30-40%），否则看起来像一丛草

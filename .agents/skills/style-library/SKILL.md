# Skill: style-library — 画风库

## 概述

维护可复用的画风提示词模板库。每种画风一个独立文件，存放于 `styles/` 子目录：

```
styles/
  01-真实纹理像素.md     ← 树类/场景类粗颗粒复古像素风
  02-精致像素风.md       ← 物品/道具/图标类精致像素风
```

每种画风 = 三部分：

```
[风格段]  ← 画风核心，固定不变（颜色、质感、笔触、渲染方式）
[要求段]  ← 通用生成约束（背景色、无文字、比例等，部分按场景调整）
[内容段]  ← 按生成对象自定义（树、物品、角色的具体描述）
```

生成时套用画风模板，只改内容段，即可产出与历史批次风格一致的内容。

## 画风索引

| 画风名 | 用途 | 状态 | 文件 |
|--------|------|------|------|
| 真实纹理像素 REALISTIC TEXTURE | 树、场景等粗颗粒复古像素 | 已验证（4 树 20 图标） | `styles/01-真实纹理像素.md` |
| 精致像素风 REFINED PIXEL ART | 物品、道具、图标精致像素 | 已验证（活力果实） | `styles/02-精致像素风.md` |

## 使用流程

### 生成画风一致的内容

1. 识别用户要求的画风（触发词：画风参考、用XX画风、同款画风）
2. 在「画风索引」表中查找对应画风文件；未收录时告知用户并询问是否登记新画风
3. 读取画风文件，复制其中的「风格段 + 要求段」
4. 按当前对象编写「内容段」（参考画风文件里的历史样例内容段写法）
5. 发起生成，完成后走正常处理管线（抠图/缩放/入库）

### 登记新画风

1. 用户给出画风来源（历史图片、其他项目样例、描述）
2. 提炼：风格段（颜色/质感/渲染方式）+ 通用要求段
3. 在 `styles/` 下新建 `NN-画风名.md`（NN 为序号，按收录顺序），文件头写 frontmatter：画风名、来源、状态
4. 在本文件「画风索引」表新增条目
5. 同时建议将完整提示词写入 `.remember/`（调用 remember 技能）

## 注意事项

1. **风格段必须原样复用**——画风一致性靠风格段逐字一致，不要随意改写措辞
2. 内容段按对象写，但色彩体系、光影手法、颗粒感等画风属性以风格段为准
3. 体型要求（如矮壮）属于对象属性，写在内容段/要求段里，不进风格段
4. 新画风登记时与已有画风对比，避免重复收录
5. 画风文件一旦验证通过，状态标记为"已验证"；后续生成应优先使用已验证画风

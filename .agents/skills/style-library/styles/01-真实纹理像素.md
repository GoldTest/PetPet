# 真实纹理像素（REALISTIC TEXTURE）

树类/场景类粗颗粒复古像素风。与「精致像素风」相反——颗粒粗、硬边、无抗锯齿、深色高对比。

## 风格段（固定，直接使用）

```
**风格：REALISTIC TEXTURE 真实纹理像素风——可见清晰像素颗粒（chunky pixel grid）、硬边像素无平滑抗锯齿、真实材质感，16-bit 复古游戏画风，颜色深而丰富、高对比度、自然大地色系。不要柔和渐变、不要粉彩淡色、不要平滑柔光。**
```

```
**要求：**
- [对象体型要求，如：矮壮敦实比例，宁矮不瘦]
- bright magenta background (#FF00FF) 品红纯色背景（用于后续抠图）
- pixel art with REALISTIC TEXTURE, 16-bit retro game art, chunky pixel grid, rough bark texture, dense speckle-textured foliage, hard-edged pixels, rich deep colors, high contrast

```

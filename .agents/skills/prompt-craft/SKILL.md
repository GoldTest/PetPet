# Skill: prompt-craft — 生图提示词制作

## 概述

从生成实践中总结的提示词七大要素框架。生图模型对"结构化的要素描述"命中率远高于"一句话描述"。
每个要素描述一个独立维度，生成时逐要素填写，最后用强约束兜底。

## 七大要素

| 要素 | 作用 | 示例 |
|------|------|------|
| 形状 | 主体轮廓/形状/比例 | 圆润球形、小巧、细长水滴形、矮壮敦实 |
| 布局方向 | 构图位置、朝向、遮挡关系 | 居中构图、主体占画面 30%、从顶部垂下、略微遮盖边缘、左上 |
| 阴影与打光 | 光源方向、明暗层次、高光 | 左上光源、2-3 层明暗色块（深色底→主色→高光点）、高光清晰聚焦 |
| 材质 | 质感、颗粒感、渲染方式 | 像素颗粒、粗颗粒硬边、光滑玻璃、绒面、无抗锯齿 |
| 内容物 | 主体本身的核心内容 | 蓝色果实、果面斑驳纹理、内部果肉 |
| 附加物 | 主体之外的点缀元素 | 叶子、光晕、藤蔓、装饰纹路、星星 |
| 强约束 | 硬性限制（必须/禁止） | 无文字、纯色背景、避开某色、单物体无杂物 |

## 组装模板

```
用 SenseNova 文生图生成一张"[画风]"图标：[对象名]。居中构图，比例 1:1（尺寸 2048x2048）。

**风格：** [画风核心描述——来自 style-library 画风库的风格段，原样复用]

**内容：** [形状 + 内容物 + 阴影与打光 + 布局方向 + 附加物，组织成 1-3 句]。

**要求：**
- [布局方向：主体占比、构图]
- [附加物：数量、大小、位置、遮挡关系]
- [材质/色彩修正]
- [颜色避开约束（与抠图背景冲突色）]
- [背景约束：颜色 + 单一均匀无渐变]
- [风格英文补充关键词]
- no text, no numbers, no labels
- 尺寸 2048x2048 (1:1)
```

## 使用流程

1. **查画风库**：生成前先查 `style-library` 画风库，风格段原样复用
2. **逐要素填写**：按七要素逐项确认，缺项会导致模型自由发挥
3. **组装**：按模板组装，内容段 1-3 句、要求段分条列出
4. **生成与抠图**：生成后走正常管线（chroma_key.py 抠图 → review 目录）
5. **迭代**：用户反馈时，一次只改一个要素，避免多个变量同时变化

## 经验教训（实测）

| 问题 | 原因 | 对策 |
|------|------|------|
| 图里有文字 | 模型忽略 no text | 开头+结尾双重强调"禁止任何文字/数字/字母/标签" |
| 背景不是纯色 | 模型生成渐变背景 | 强调"单一均匀纯色，无渐变、无其他颜色" |
| 主体被抠图误删 | 主体色接近背景色 | 提前约束主体避开背景色系（品红背景→禁浅红浅粉） |
| 内容物分散/多物体 | 提示词未强调"只有这一个" | 加"画面中只有…没有其他杂物、碎片或多余物体" |
| 尺寸不合适 | 只写"不大不小"模糊词 | 给量化占比（30% / 40% / 70%） |
| 反复重生成 | 一次改多个要素无法定位问题 | 单要素迭代；"重新生成"时提示词一字不改 |
| 叶子/附加物比例失衡 | 附加物未给大小约束 | 附加物写数量 + 大小（中等/偏大）+ 位置（顶部垂下） |
| 光效变柔和光晕 | 画风禁柔和渐变但未约束光效 | 光效单独描述：紧贴轮廓、边界分明、不扩散 |

## 要素优先级

强约束 > 材质 > 内容物 > 阴影与打光 > 形状 > 布局方向 > 附加物

当生成结果偏离要求时，优先检查高优先级要素是否写清楚；附加物细节（如叶子数量）最容易被模型忽略，需写数量+大小+位置三件套。
